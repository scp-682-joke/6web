# Assignment 6 — jQuery

Zhibek Slambek | SE-2530

Five connected pages demonstrate jQuery selectors, effects, DOM manipulation,
form input, and animations. Part 5 is an accordion study guide.

## Run
Open index.html in a browser and use the navigation to visit each part.
An internet connection is required to load jQuery 3.7.1 from the CDN.
There is no build step, package installation, or additional plugin.

## Tasks
- Part 1: CDN setup, document ready, console message, ID/class/tag selectors,
  text(), html(), and css().
- Part 2: hide/show/toggle, image fades, and sliding panels.
- Part 3: append/prepend/remove, image and link attributes, and live form preview.
- Part 4: basic, sequential, and combined animations. Click again to replay.
- Part 5: accordion with slide animations; only one topic stays open at a time.

All pages use the existing shared style.css and a simple script.js in their own
folder. The two SVG landscape illustrations in images are original project assets.

## Publish with GitHub Pages
1. Push these files to the GitHub repository, preserving the folder structure.
2. In repository Settings → Pages, select Deploy from a branch.
3. Choose the branch containing the assignment and the / (root) folder, then Save.
4. Wait for deployment and open the URL shown by GitHub.
5. Submit the repository link as required by the assignment.

Alternatively, deploy this folder to Netlify as a static site with no build command.

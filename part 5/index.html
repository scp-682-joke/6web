Part 5. Mini Project

Task 11. Interactive Accordion Menu

A small study guide. Select a topic to open or close it.

A selector finds HTML elements. Use # for an ID, . for a class, or a tag name such as p.

$("#title").text("Hello!");

Effects change visibility. Try fading an image or sliding a panel open and closed.

$("#panel").slideToggle(400);

Use animate() to change numeric CSS properties over time. Chain calls to run them in order.

$("#box").animate({ left: 100 }, 600);
